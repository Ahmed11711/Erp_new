# Magalis Mobile (Flutter UI)

تطبيق موبايل لواجهة نظام **Magalis ERP** — تصميم فقط ببيانات وهمية، بدون ربط بالباكند.

## الشاشات

- Splash + تسجيل الدخول
- الرئيسية (KPIs، العمليات، مسار التشغيل، أحدث الطلبات)
- الطلبات + **لوحة فلاتر كاملة** مطابقة لويب `list-orders` + تفاصيل الطلب
- عروض الأسعار + تفاصيل العرض
- الإشعارات
- القائمة / Drawer: سايدبار النظام بالكامل مثل الويب

## فلاتر الطلبات

لوحة قابلة للطي بنفس حقول الويب تقريباً: نوع العميل/الطلب، شركة الشحن، الحالة، المصدر، طريقة/خط الشحن، المراجعة، Shopify، التحصيل، VIP/نواقص/مدفوع، التواريخ، المحافظة/المدينة، اسم/هاتف/رقم طلب/بوليصة/منتج.

## الألوان

نفس هوية الويب: Primary `#82225E` · Navy `#0E4057`

## التشغيل

يتطلب [Flutter SDK](https://docs.flutter.dev/get-started/install).

```bash
cd magalis_mobile
flutter pub get
flutter run
```

للمعاينة السريعة على الويندوز:

```bash
flutter run -d windows
```

أو على متصفح:

```bash
flutter run -d chrome
```

## الاختبارات

```bash
flutter test
```

تشمل: منطق الفلاتر، واجهة لوحة الفلترة، شاشة الطلبات، ومحتوى السايدبار.

## ملاحظة

أي إجراء (دخول، شحن، تحصيل، تحويل عرض…) محلي فقط — لا يوجد استدعاء API.

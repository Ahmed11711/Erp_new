استيراد Excel والجرد

الأصناف والأرصدة الافتتاحية وتسوية الجرد الفعلي تتم من هنا عبر ملفات ‎.xlsx / .xls‎ أو ‎.csv‎ (نفس الأعمدة). صلاحيات API تطابق مسار المشتريات (إداري، محاسبة، لوجستيات).

النماذج محفوظة بـ Unicode UTF-16 وفاصل TAB بين الأعمدة حتى يعرض Excel كل عمود منفصلاً (وليس كل البيانات في خلية واحدة). يمكن أيضاً استخدام فاصلة منقوطة أو فاصلة؛ الخادم يكتشف الفاصل تلقائياً.

1) إضافة / تحديث الأصناف (بدون كميات مخزون)

إلزامي: اسم الصنف، سعر التكلفة. يُفضّل تحديد: المخزن (الافتراضي مخزن مواد خام)، رقم الوحدة (أو يُستخدم 1)، رقم الانتاج أو فرع الانتاج (اسم خط الإنتاج كما في النظام). اختياري إضافي: كود الصنف، اللون، المرجع، الحد الأدنى.
